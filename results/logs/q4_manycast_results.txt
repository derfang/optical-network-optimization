======================================================================
Question 4: Manycast Routing and Wavelength Assignment (RWA)
Comparative Analysis of Path Generation Strategies
======================================================================

Strategy 1: Single Best Shortest Path Only (K = 1)
----------------------------------------------------------------------
- Candidate Paths Generated: 16 paths
- Total Binary Decision Variables: 152
- Solver Status: optimal
- Max Wavelength Index (W_high): 6
- Total Network Routed Distance: 573 km
- Execution Runtime: 67.6 ms
- Analysis: Strictly chooses the minimum physical distance route for every source-destination pair without considering wavelength clash or link congestion. Because alternative routes are not available, overlapping requests on shared links force the solver to allocate higher wavelength channels (up to W6).

Strategy 2: Yen's K-Shortest Weighted Paths (K = 2 / K = 3 - Balanced)
----------------------------------------------------------------------
- Candidate Paths Generated: 32 paths
- Total Binary Decision Variables: 280
- Solver Status: optimal
- Max Wavelength Index (W_high): 5
- Total Network Routed Distance: 606 km (+5.7% vs. K=1)
- Execution Runtime: 160.9 ms
- Analysis: Optimal engineering trade-off. By providing K=2 shortest paths, the solver can choose short detours around congested fiber links, reducing peak wavelength usage from W6 to W5 while maintaining close to minimal propagation delay.

Strategy 3: All Possible Simple Paths (Unconstrained Routing)
----------------------------------------------------------------------
- Candidate Paths Generated: 133 paths (8.3x larger than K=1)
- Total Binary Decision Variables: 1088 (7.2x larger than K=1)
- Solver Status: optimal
- Max Wavelength Index (W_high): 3
- Total Network Routed Distance: 1195 km (+108.5% vs. K=1)
- Execution Runtime: 710.7 ms (10.5x slower)
- Analysis: The solver explores every possible topological path regardless of hop count or physical distance. While it manages to compress spectrum usage down to W_high = 3, it does so by routing traffic through wildly convoluted loops (total network distance jumps to 1195 km), which increases optical signal attenuation, dispersion, and amplifier noise while dramatically inflating solver time and memory.
